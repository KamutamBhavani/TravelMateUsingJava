Travel Console Application

Overview

This is a console-based traveling application developed in Java. The application allows users to explore different travel destinations, get information about places, and plan trips efficiently. The application utilizes the Map data structure to store and manage travel-related data efficiently.

* Features

View a list of available travel destinations.

Get detailed information about a selected destination.

Plan and organize travel routes.

Efficient data retrieval using Map.

Interactive console-based interface.

* Technologies Used

Programming Language: Java

Data Structure: Map (HashMap, TreeMap, etc.)

Development Environment: Any Java-supported IDE (Eclipse, IntelliJ IDEA, VS Code, etc.)


java Main

* Usage

Follow on-screen prompts to navigate through the application.

Enter destination names to get details.

Plan trips by selecting available routes.
